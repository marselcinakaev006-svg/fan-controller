# Fan Controller

Проект управления вентилятором с ПИ-регулятором на базе микроконтроллера ATmega16. Позволяет автоматически поддерживать обороты в зависимости от температуры, а также управлять вручную через графический интерфейс на ПК.

## Возможности

- 🔄 Автоматический режим с гистерезисом по температуре
- 🎛️ Ручной режим с плавной регулировкой оборотов
- 📟 Отображение текущих оборотов (RPM), уставки и ШИМ
- 💾 Сохранение параметров в EEPROM
- 🖥️ Графический интерфейс на Processing (Windows)
- 🌡️ Отправка реальной температуры CPU (через OpenHardwareMonitor)

## Аппаратная часть

- Микроконтроллер: **ATmega16**
- Вентилятор: с тахометрическим выходом (2 импульса на оборот)
- Датчик температуры: заглушка в коде (50°C), в реальном проекте — DS18B20 или аналог
- Интерфейс управления: UART (9600 бод)

## Структура репозитория

- `firmware/` — исходный код для AVR (C, Atmel Studio)
- `processing/` — графический интерфейс для ПК (Processing)
- `schematics/` — схемы подключения (если есть)

## Как использовать

### Прошивка контроллера

1. Откройте проект в Atmel Studio.
2. Скомпилируйте и прошейте ATmega16.
3. Подключите вентилятор и датчик (если есть).

### Графический интерфейс

1. Установите [Processing](https://processing.org/).
2. Установите библиотеку JavaFX (Sketch → Import Library → Add Library → JavaFX).
3. Откройте скетч из папки `processing/`.
4. Запустите. Выберите COM-порт и скорость 9600.
5. Используйте кнопки AUTO/MANUAL, ползунок RPM и поля параметров.

### Управление по UART

Команды:

- `set_rpm <значение>` — задать обороты в ручном режиме
- `auto` — включить автоматический режим
- `manual` — включить ручной режим
- `set_temp_off <значение>` — температура выключения
- `set_temp_on <значение>` — температура включения
- `set_temp_max <значение>` — максимальная рабочая температура
- `set_fan_min <значение>` — минимальные обороты
- `set_fan_max <значение>` — максимальные обороты
- `set_temp <значение>` — текущая температура (для автоматического режима)
